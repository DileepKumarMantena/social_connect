Social Connect - Developer Setup Guide
==========================================

This guide will help you set up the Social Connect application from scratch.
Social Connect is a full-stack web application with a React frontend and FastAPI backend.

==========================================
PREREQUISITES
==========================================

Required Software:
- Node.js (v16 or higher)
- Python (v3.8 or higher)
- MongoDB (v5.0 or higher)
- Git
- Code Editor (VS Code recommended)

Optional but Recommended:

- MongoDB Compass (for database GUI)
- Chrome Developer Tools


==========================================
INSTALLATION STEPS
==========================================

1. CLONE THE REPOSITORY
-----------------------
git clone <repository-url>
cd social_connect

2. BACKEND SETUP
----------------

2.1. Create Python Virtual Environment
--------------------------------------
# On macOS/Linux
python3 -m venv backend/venv
source backend/venv/bin/activate

# On Windows
python -m venv backend/venv
backend\venv\Scripts\activate

2.2. Install Python Dependencies
--------------------------------
cd backend
pip install -r requirements.txt

2.3. Verify MongoDB Installation
--------------------------------
# Make sure MongoDB is running
mongosh --eval "db.adminCommand('ping')"

# Expected output: { ok: 1 }

2.4. Initialize Database
-------------------------
# Run the MongoDB initialization script
python init_mongodb.py

# This will:
# - Connect to MongoDB
# - Create collections
# - Insert sample data
# - Create indexes

3. FRONTEND SETUP
-----------------

3.1. Install Node Dependencies
------------------------------
cd ../src
npm install

3.2. Environment Configuration
-------------------------------
# Create environment file in src/
# Create .env file with the following content:
REACT_APP_API_LINKS=http://localhost:8003

Note: The backend runs on port 8003 by default.

==========================================
RUNNING THE APPLICATION
==========================================

1. START MONGODB (if not already running)
------------------------------------------
# On macOS with Homebrew
brew services start mongodb-community

# On Windows
net start MongoDB

# On Linux
sudo systemctl start mongod

2. START BACKEND SERVER
-----------------------
cd backend
source venv/bin/activate  # On Windows: venv\Scripts\activate
python extension.py

Expected Output:
INFO: Connected to MongoDB: social_connect
INFO: Application startup complete.
INFO: Uvicorn running on http://0.0.0.0:8003

3. START FRONTEND DEVELOPMENT SERVER
------------------------------------
Open a new terminal window:
cd src
npm start

Expected Output:
Starting the development server...
Compiled successfully!
You can now view social-connect in the browser.
Local:            http://localhost:3000

==========================================
DEVELOPMENT WORKFLOW
==========================================

1. Making Changes to Backend:
----------------------------
- Edit files in backend/ directory
- Restart the backend server (Ctrl+C, then python extension.py)
- Test changes using http://localhost:8003/docs

2. Making Changes to Frontend:
------------------------------
- Edit files in src/ directory
- Frontend automatically reloads on save
- Changes appear immediately in browser at http://localhost:3000

3. Database Changes:
-------------------
- Modify backend/constants.py for mock data
- Run python init_mongodb.py to reinitialize MongoDB
- Or use MongoDB Compass for manual changes

4. Testing API Endpoints:
------------------------
- Use Swagger UI: http://localhost:8003/docs
- Or use Postman with the collection in ENDPOINTS.txt
- All endpoints (except login) require JWT authentication
